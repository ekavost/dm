# DM Marketing

Landing page para servicios de marketing digital en Kazajstán. Sitio web de marketing enfocado en servicios de publicidad contextual, targetizada y analítica web.

## 📋 Secciones del Sitio

- **Hero** - Sección principal con llamado a la acción
- **Servicios** - Descripción de servicios ofrecidos
- **Proceso** - Flujo de trabajo y metodología
- **Precios** - Planes y tarifas
- **Auditoría** - Solicitud de auditoría gratuita
- **Contacto** - Formulario de contacto

## 🛠️ Tecnologías

- [Nuxt 4](https://nuxt.com/) - Framework Vue.js
- [Vue 3](https://vuejs.org/) - Framework JavaScript progresivo
- [Nuxt UI](https://ui.nuxt.com/) - Librería de componentes
- [Tailwind CSS](https://tailwindcss.com/) - Framework CSS
- [TypeScript](https://www.typescriptlang.org/) - Superset de JavaScript
  

## 🚢 Despliegue

Este proyecto está configurado para desplegarse en GitHub Pages:

1. El preset de Nitro está configurado para `github-pages`
2. La variable `NUXT_APP_BASE_URL` se puede configurar en el workflow de GitHub Actions
3. Ejecuta `npm run generate` para crear el sitio estático


## 🌍 Idioma

El sitio está configurado en ruso (`lang="ru"`) para el mercado de Kazajstán.


## 🔧 Configuración

- **Base URL**: Configurada dinámicamente para GitHub Pages
- **Fuentes**: Space Grotesk, Inter, JetBrains Mono desde Google Fonts
- **SEO**: Configurado con meta tags para marketing digital
